IMPORTANT:
A website cannot become publicly searchable merely by creating HTML on a computer. It needs FREE hosting and a public URL.
The easiest free option is GitHub Pages:
1. Create a free GitHub account.
2. Create a new public repository named fizera-process-technology.
3. Upload index.html and the assets folder.
4. Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
5. GitHub will give you a public address such as:
   https://YOUR-USERNAME.github.io/fizera-process-technology/
6. Anyone can open that URL.

For Google search:
- The free GitHub Pages URL can be indexed by Google, but indexing is not instant.
- For a professional address such as fizera.in, a domain name normally has to be purchased separately; the hosting can still be free.
